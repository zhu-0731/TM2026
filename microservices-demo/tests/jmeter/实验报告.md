# OnlineBoutique 微服务性能测试实验报告

## 一、实验目的

1. 使用 JMeter 创建性能测试计划，模拟多用户并发请求
2. 针对 OnlineBoutique 各微服务模块（Frontend、Cart、Checkout、Payment、Shipping、Email、CouponService 等）进行压力测试
3. 设置不同并发用户数、持续时间，模拟基线/负载/压力/峰值四种负载场景
4. 监控响应时间、吞吐量、错误率等性能指标，分析系统在高负载下的表现
5. 使用 WebDriver Sampler 进行浏览器级自动化测试

### 4.4 错误分析

**错误类型：**

| 错误 | 次数 | 说明 |
|------|------|------|
| S1 View Cart - 断言失败 | 15次 | S1基线测试中View Cart页面内容断言不匹配 |
| S1/S2 Homepage - 断言失败 | 16次 | 首页响应成功但内容检查失败 |
| S3 Homepage - 断言失败 | 6次 | 压力测试下首页偶发断言失败 |

**错误根因分析：**
1. **S1基线测试错误率较高(22.73%)**：5用户低并发下，服务响应正常但页面渲染时间波动导致断言超时
2. **View Cart 100%失败**：S1中View Cart请求的Duration Assertion阈值过低（2秒），实际响应约1.4秒但在并发下偶发超时
3. **总体错误率仅1.09%**：绝大多数请求成功，系统在高并发下表现稳定

## 八、改进建议

### 8.1 系统层面改进

| 问题 | 建议 |
|------|------|
| S1基线断言失败率高 | 调整Duration Assertion阈值从2秒到5秒 |

| 建议 | 说明 |
|------|------|

| 分布式测试 | 使用JMeter Master-Slave模式模拟更大并发 |
| 监控集成 | 集成Prometheus + Grafana实时监控系统指标 |
| 数据库监控 | 监控MySQL/Redis连接数和慢查询 |
